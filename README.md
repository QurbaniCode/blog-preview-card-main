# Blog Preview Card

A responsive blog preview card built as a Frontend Mentor challenge using HTML5 and CSS3.

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Custom Properties
- Responsive Design
- `@font-face`
- Figtree Variable Font

## Features

- Responsive layout for desktop and mobile screens
- Flexbox-based layout
- Custom CSS variables for colors, typography, spacing, border radius, and shadows
- Responsive card sizing using `width` and `max-width`
- Custom Figtree font loaded with `@font-face`
- Hover effects and CSS transitions
- Meaningful `alt` text for images
- Clean and maintainable CSS structure

## What I Learned

While building this project, I practiced:

- Structuring a webpage using HTML5
- Creating responsive layouts with Flexbox
- Using CSS Custom Properties for reusable design values
- Working with responsive card dimensions
- Loading local fonts using `@font-face`
- Creating hover effects and CSS transitions
- Using meaningful `alt` attributes for better accessibility
- Organizing CSS into reusable sections
